# Deformable Object Perception and Manipulation with a Robot

This repository contains public artifacts from my diploma thesis work:

**Thesis topic:** *Zaznavanje in manipulacija deformabilnih objektov z robotom*

The project focuses on perception and robotic manipulation of deformable objects, demonstrated with a robot setup, vision system, conveyor belt, and bread dough experiments.
